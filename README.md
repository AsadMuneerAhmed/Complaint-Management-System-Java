# Complaint-Management-System-Java
A java-based Complaint Management System for Municipal Services using Netbeans and MySQL with GUI forms. 
Complaint Management System is a Java-based desktop application developed using NetBeans IDE and MySQL database.
It provides an efficient way to manage complaints and user data in an organized manner. The system allows users to register, log in, submit complaints, and track their status, while the admin can view, search, delete, and manage users or complaints through an interactive GUI.

**Key Features**
User Registration & Login — New users can register and log in securely.
Add Complaint — Users can submit complaints with details like category, date, and description.
View Complaints — All submitted complaints are displayed in a table format.
Search Functionality — Staff Members can search complaints or users by email or complaint ID.
Delete & Refresh — Staff Members can delete data from the database and refresh the table instantly.
User Management — Staff Members can view all registered users and perform operations like search, delete, and refresh.
Database Integration — Fully connected with MySQL, ensuring data persistence and accuracy.

**Technologies Used**
Programming Language: Java
IDE: NetBeans
Database: MySQL
Connector: JDBC (Java Database Connectivity)
UI Framework: Java Swing

**How to Run the Project**
Open project in NetBeans IDE.
Import the MySQL database (complaint_management.sql).
Configure your database connection in the code (username, password).
Run the main form (e.g., WelcomePage.java).
